# ИИ в журналистике — сайт-презентация

Красочная презентация из **5 слайдов** об искусственном интеллекте в журналистике.
Каждый слайд сопровождается **процедурно сгенерированной иллюстрацией** (PNG, 1024×768).

## Слайды

1. **Введение** — ИИ в журналистике: новая эпоха новостей
2. **Алгоритмы** — как машины собирают и генерируют новости 24/7
3. **Симбиоз** — человек + ИИ: редакция будущего
4. **Данные** — журналистика данных с поддержкой LLM
5. **Этика** — дипфейки, прозрачность и будущее профессии

## Управление

- стрелки ← → , пробел, PageUp/PageDown, Home/End
- колесо мыши и свайпы на мобильных
- точки-навигатор внизу, автопоказ каждые 9 секунд (кнопка «Автопоказ»)

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # продакшн-сборка в dist/
```

## Стек

React 18 · TypeScript · Vite · Tailwind CSS 4 · Framer Motion
