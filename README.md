# ШАБАШКА — маркетплейс подработок для подростков 14–17 лет

Одностраничный сайт-маркетплейс: лента проверенных подработок с фильтрами,
поиском и откликами, калькулятор дохода с лимитами по ТК РФ, блок для
родителей с гарантиями и FAQ, отзывы и живые детали интерфейса.

## Стек

- **React 18** + **TypeScript**
- **Vite 6** — сборка и dev-сервер
- **Tailwind CSS v4** (подключён через `@tailwindcss/vite`)
- **JSZip** — сборка архива исходников прямо в браузере (ленивый чанк)
- Шрифты: Unbounded (дисплей), Golos Text (текст), JetBrains Mono (числа и теги) — с Google Fonts

## Что нужно для запуска

- **Node.js 18 или новее** (проверить: `node -v`)
- **npm** (идёт вместе с Node, проверить: `npm -v`)

## Установка и запуск на компьютере

```bash
# 1. Перейти в папку проекта
cd shabashka

# 2. Установить зависимости (создаст node_modules/)
npm install

# 3. Запустить dev-сервер
npm run dev
```

Открой в браузере адрес, который покажет терминал — обычно
**http://localhost:5173**. Изменения в коде подхватываются мгновенно (HMR).

Остановить dev-сервер: `Ctrl + C` в терминале.

## Продакшен-сборка

```bash
# Собрать оптимизированную версию в папку dist/
npm run build

# Посмотреть собранную версию локально
npm run preview
```

Папку `dist/` можно залить на любой статический хостинг
(Netlify, Vercel, GitHub Pages, nginx) — сайт полностью статический,
бэкенд не нужен.

## Структура проекта

```
index.html                  — HTML-обёртка, шрифты, meta
vite.config.js              — конфигурация Vite + плагин Tailwind
tsconfig.json               — настройки TypeScript
src/
  main.tsx                  — точка входа React
  App.tsx                   — сборка секций, бегущая лента, live-тосты
  index.css                 — тема Tailwind v4, анимации, утилиты
  data.ts                   — ВСЕ данные: заказы, категории, гарантии, FAQ, отзывы
  lib.tsx                   — хуки: scroll-reveal, count-up, scramble, localStorage
  projectFiles.ts           — упаковка исходников в ZIP (кнопка в футере)
  vite-env.d.ts             — типы для импортов ?raw
  components/
    Icons.tsx               — набор кастомных SVG-иконок
    Nav.tsx                 — шапка с меню и кнопкой откликов
    Hero.tsx                — постерный первый экран + счётчики
    JobBoard.tsx            — лента подработок: поиск, фильтры, избранное, отклики
    HowItWorks.tsx          — 4 шага до первой зарплаты (sticky-колонка)
    Calculator.tsx          — калькулятор дохода со слайдером часов
    Safety.tsx              — блок для родителей: гарантии + аккордеон FAQ
    Voices.tsx              — отзывы-«открытки»
    Faq.tsx                 — FAQ с вкладками «Подросткам / Родителям»
    Closing.tsx             — CTA-банда, футер, кнопка «Скачать исходники»
```

## Как менять контент

Все тексты и данные лежат в **`src/data.ts`**:

- `JOBS` — список подработок (название, ставка, категория, возраст, район…)
- `CATEGORIES` — фильтры ленты, `CALC_CATS` — направления калькулятора
- `GUARANTEES`, `PARENTS_FAQ`, `TEENS_FAQ` — блоки доверия
- `TESTIMONIALS` — отзывы, `LIVE_EVENTS` — всплывающие события платформы

Цвета и шрифты темы настраиваются в блоке `@theme` в **`src/index.css`**.

## Возможные проблемы

| Проблема | Решение |
|---|---|
| `npm: command not found` | Установи Node.js с nodejs.org (LTS) |
| Порт 5173 занят | Vite сам предложит другой порт, смотри терминал |
| Ошибки после обновления кода | `rm -rf node_modules && npm install` |
| Шрифты не грузятся | Нужен доступ в интернет (Google Fonts) |
